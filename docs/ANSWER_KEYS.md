# 공식 정답표 추출 (정답 · 배점 · 해설 쪽)

게시된 공식 **정답 및 해설 PDF** 와 **문제지 PDF** 에서 문항별 정답·배점·해설 시작 쪽을 추출해,
검증을 통과한 슬롯만 `questions` 에 게시합니다. 자동 채점·정답 바로 보기·문항별 해설(해설지 쪽 이동)이 이 데이터로 동작합니다.

```bash
npm run answers:extract -- --year=2025 --dry-run          # 결과만 보기 (DB 쓰기 없음)
npm run answers:extract -- --year=2025                    # answer_key_extractions 에 기록 (게시 안 함)
npm run answers:extract -- --year=2025 --publish          # 검증된 슬롯만 questions 에 게시
npm run answers:extract -- --exam=<exam id> --force       # 같은 파서 버전으로 처리한 시험도 다시
```

## 무엇을 요청하나

- `exam_files` 중 실제 시험(`is_sample=false`)의 공식 redirect 자료(`solution`, `question`)만.
- **정책상 파일 요청이 허용된 호스트만** (`src/ingestion/sources/policy.ts` 의 `fetch_file` — 현재 EBSi 파일 서버
  `wdown.ebsi.co.kr`, robots.txt 없음). KICE·교육청 URL 은 요청하지 않고 `unsupported` 로 셉니다.
- SafeFetcher: https · allowlist · redirect 마다 재검증 · 사설 IP 차단 · 요청 간격 1.5초 · 최대 40MB · `%PDF-` 서명 확인.
- 같은 파일을 여러 슬롯이 가리키면 한 번만 받습니다. 해설 본문은 저장하지 않습니다 (정답·배점·쪽 번호만).
- 같은 파서 버전(`ANSWER_KEY_PARSER_VERSION`)으로 처리한 시험·영역은 건너뜁니다.

## 정답표 파싱 (`src/ingestion/answer-keys/parse.ts`)

| 형식                             | 예                                                  | 처리                                                                  |
| -------------------------------- | --------------------------------------------------- | --------------------------------------------------------------------- |
| 평가원 모의평가·수능 해설 (EBSi) | `01. ① 02. ④ …`, 수학 단답형 `18. 133`              | 1쪽 첫 문항 머리말 이전 또는 `■ [공통/선택: …]` 머리말 다음의 표 줄   |
| 공통/선택 구분                   | `■ [공통: 독서·문학]` · `■ [선택: 화법과 작문]`     | 선택 과목명 → course code (`resolveCourse`), 공통 = course 없음       |
| 교육청 학력평가 해설             | `정답` 줄 다음 `1 ⑤ 2 ④ …`, `22 3 23 55 …`          | "…정답" 줄 바로 다음 + 번호가 연속일 때만 (쪽 머리 `5 27` 오인 방지)  |
| 텍스트 층에서 흩어진 표          | `01. 02. … 10.⑤ ② ③ …`                              | 순서대로 짝짓되 `reordered` 표시 → **본문 정답 표기와 모두 일치해야** |
| 문항 머리말 (해설 쪽)            | `12. 원소의 주기적 성질`, 흩어진 `이온화 에너지10.` | 번호 순서대로만 인정                                                  |
| 본문 정답 표기                   | `정답④`, `정답 ⑤`                                   | 교차 확인 (없으면 표만으로 검증)                                      |

## 검증 (`validate.ts`, `assemble.ts`) — 하나라도 실패하면 `manual_review`

- 문항 수: 국어 45 · 수학 30 · 영어 45 · 한국사/탐구 20 · 제2외국어 30. 공통 + 각 선택 = 총 문항, 선택은 공통 다음 번호부터.
- 번호 연속 · 중복 모순 없음 · 선택형 1~5 · 단답형은 수학만 0~999 정수.
- 본문 정답 표기가 있으면 모두 일치. 흩어진 표의 값은 표기가 **반드시** 있어야 함.
- 같은 슬롯이 여러 해설 파일에 있으면 모두 같아야 함.
- 머리말이 기대한 학년도·월·영역·과목과 **모순**되면 거부 (머리말이 이미지라 언급이 없는 것은 허용).
- 배점: 문제지 한 부의 문항 수 = 총 문항, 합계 = 만점(국어·수학·영어 100, 그 외 50), 표기 없는 문항은 2점(제2외국어 1점),
  허용 범위(수학 2~4, 제2외국어 1~2, 그 외 2~3). 문제지와 해설의 EBSi 파일 코드가 다르면(`s_his` ≠ `g_che1`) 쓰지 않음.
- 공통 배점은 여러 문제지가 모두 같아야 함. 통합 문제지(선택 과목 전부가 한 파일)는 공통 배점에만 사용.
- 배점을 검증할 수 없으면 정답이 맞아도 게시하지 않음 (`questions.score` 는 필수이고, 추정하지 않는다).

## 게시

- 이미 있는 문항의 정답과 다르면 **덮어쓰지 않고** `conflicts_existing` 으로 manual_review.
- 세부과목 페이지는 과목 문항 + 번호가 겹치지 않는 공통 문항으로 채점 (예: 화법과 작문 = 공통 1~34 + 35~45).
- 게시 후 해당 시험 페이지를 revalidate (`NEXT_PUBLIC_SITE_URL` + `CRON_SECRET` 이 있을 때).

## 개념 태그 (parser v3, migration 0014)

`--publish` 로 슬롯을 게시할 때 해설지 문항 머리말 제목을 개념 태그로 연결한다 (`concepts`, `question_concepts`).

- 근거: 공식 정답·해설 PDF 의 문항 머리말만 ("1. 탄소 화합물", "1. [출제 의도] 목적 파악"). 제목을 요약·생성하지 않는다.
- 정리 규칙 (`src/lib/concepts.ts`): NFKC, "출제 의도" 표지 제거, 가운뎃점·공백 통일, 문장부호·정답 표기·물음표가 있는 제목은 버림. 같은 과목의 같은 slug 는 한 개념.
- 자동 승인: 검증된 정답표 + 번호가 앞에 오는 정상 머리말 + 순서가 흩어지지 않은 표 + 명사형 제목.
- 검토 대기(manual_review): 번호가 뒤로 밀린 머리말, 흩어진 표, 문장형 출제의도("출제의도 : …을 이용하여" — 줄바꿈으로 잘렸을 수 있음).
- 각 연결에 근거(머리말 원문 + 해설지 쪽), 출처 파일 id·URL, 신뢰도를 남긴다.
- 관리자: `/admin/concepts` 에서 승인·거절·이름 수정 (slug 는 유지). 공개 화면(문항 카드, `/concepts/{영역}/{slug}`)에는 승인된 연결만 나온다.
- 이미 있는 연결은 다시 추출해도 덮어쓰지 않는다 (관리자 결정 보호).

배포 후 한 번: `npm run db:migrate:prod` → `npm run answers:extract -- --publish` (파서 버전이 v3 로 올라 이전 슬롯이 다시 처리된다. 정답이 바뀌지 않으면 기존 문항은 그대로이고 개념 연결만 추가된다).
