# 실제 데이터 coverage (운영자 CSV 입력)

작성: 2026-09-25 · 대상: 2023·2024·2025년 시행 고1·고2·고3 시험 · 상태: **전부 `manual_review` (미게시)**

## 방법

- robots.txt 가 막는 페이지(EBSi `.ajax`, KICE/수능 전체)는 요청하지 않았다.
- 검색엔진이 공개 색인한 결과의 `url` 필드만 기록했다. URL 을 만들거나 고치지 않았다. 모든 URL 은 EBSi 공식 다운로드 호스트 `wdown.ebsi.co.kr` 이다.
- `wdown.ebsi.co.kr` 은 robots.txt 가 없다(404). 발견된 URL 마다 HEAD 1회로 존재만 확인했다(본문 다운로드 없음, 1.5초 간격). **확인한 URL 은 모두 200 + PDF 였다.**
- 슬롯 판정 (`scripts/official-url-search/build.py`):
  - 연·월·학년: 공식 경로 `/01exam/YYYYMMDD/goN/`. 단, 그 날짜 경로의 검색 결과 제목 중 하나라도 해당 월(또는 수능)을 명시해야 인정한다.
  - 자료 종류: 파일명 `_mun_`(문제) · `_hsj_`(정답 및 해설) · `_scr`(듣기 대본) · `live_main_paper_1_`(수능 홀수형 문제지).
  - 선택과목: `s_samun` 같은 코드는 같은 코드의 검색 결과 제목이 과목명을 정확히 하나 명시할 때만 매핑한다. 고2·고3 `sat`/`gat` 는 파일마다 제목으로만 판정한다.
  - 국어·수학의 `korA`/`korB`/`mathA`/`mathB` 는 의미가 확인되지 않아 **넣지 않았다**. 한 슬롯에 서로 다른 파일이 둘 이상이어도 넣지 않았다.
- 결과 파일:
  - `data/imports/official-urls.csv`: import 한 행
  - `data/imports/evidence/<연도>.json`: 행마다 검색어·검색 결과 제목·HEAD 결과, 보류 목록과 사유

`npm run import:official-urls -- --file=data/imports/official-urls.csv --admin=<email>` 로 넣으면 309행이 모두 `manual_review` 로 저장된다(재실행 시 전부 "동일"). 게시하려면 `/admin/imports` 에서 브라우저로 확인한 뒤 승인해야 한다.

## 요약

기대 슬롯 = 시험마다 아래 과목 × (문제, 정답 및 해설) + 영어 듣기 음원. 듣기 대본은 선택 자료라 제외했다.

- 고1: 국수영한 + 통합사회·통합과학
- 고2: + 사탐 9 · 과탐Ⅰ 4
- 고3 학평: + 사탐 9 · 과탐 8
- 고3 모평·수능: + 직탐 6 · 제2외국어/한문 9

**행이 하나도 발견되지 않은 시험은 기대 슬롯에 들어 있지 않다.** 월 미확인으로 보류한 시험도 같다.

- CSV 행 수와 "채운 기대 슬롯" 이 다른 것은 기대 모델 밖의 실제 자료 때문이다(예: 2024년 10월 **고2** 제2외국어/한문, 고3 10월 학평 제2외국어, 영어 듣기 대본).
- 카탈로그는 제2외국어/한문을 고3 전용으로 두지만 EBSi 공식 경로에는 고2 파일이 있다. 승인 전에 확인해야 한다.
- 영어 듣기 **MP3 는 검색엔진에 하나도 색인되지 않았다**. 전부 누락이다.

- **시험 월 미확인**: `YYYY0430/go3`(2023-04-30 은 일요일)와 `20231219/go1·go2` 는 어떤 제목도 그 월을 말하지 않는다. 경로 날짜가 시행일이 아니라 게시일일 수 있다(아마 고3 5월 학평, 고1·2 11월 학평). 실제 월을 확인하면 CSV 에 직접 넣으면 된다.
- 보류 URL 과 사유는 `data/imports/evidence/<연도>.json` 의 `held` 에 있다.

## 한계

- 검색엔진이 색인한 파일만 찾을 수 있다. 에이전트마다 검색 횟수 제한이 있어 연도마다 약 120~150회를 검색했다. 누락 슬롯 중 상당수는 공식 파일이 있어도 색인되지 않았거나 이번 검색에 걸리지 않은 것이다. **누락 = 공식 자료 없음이 아니다.**
- KICE(`suneung.re.kr`)는 robots `Disallow: /` 라 HEAD 도 보내지 않았고 CSV 에도 넣지 않았다. 수능·모평 원본은 EBSi 경로의 파일만 들어가 있다.
- 조직(organizer)은 평가원 시험만 채웠다. 학평 주관 교육청은 추측하지 않고 비워 두었다.

## 다시 실행

```bash
# found/*.json 에 검색 결과 {url,title,query} 를 모은 뒤 (URL 은 결과 그대로)
WORK=<작업 폴더> python3 scripts/official-url-search/head.py 2025    # HEAD 존재 확인 (wdown.ebsi.co.kr 만)
WORK=<작업 폴더> python3 scripts/official-url-search/build.py 2025 <작업 폴더>/head.json
WORK=<작업 폴더> python3 scripts/official-url-search/gap.py 2025
WORK=<작업 폴더> python3 scripts/official-url-search/evidence.py 2025 > data/imports/evidence/2025.json
```
