# 독해 학습 노트 (study_materials · reading_note)

운영자가 **직접 쓴** 짧은 메모만 넣습니다. AI 보조로 만든 메모는 `origin: "ai_assisted"` 로 표시하면
화면에 "AI 보조 생성 · 검토 필요"가 붙습니다.

- 지문 전문·긴 인용 금지 (항목당 200자 제한). 원문은 공식 문제지·해설 PDF 링크로 안내합니다.
- 입력하면 `reviewing` 상태로 들어가고, `/admin/study` 에서 승인 → 게시해야 공개됩니다.

```bash
npm run study:import-notes -- --file=data/study/example.json --dry-run
npm run study:import-notes -- --file=data/study/example.json
```

형식은 `template.json` 참고.
